Desafio 01 — Estatísticas de uma lista

Neste desafio, pratiquei:

- "ArrayList"
- "for"
- ".get()"
- ".size()"
- "if / else"
- Operador "%"
- Soma de valores
- Contagem de números pares e ímpares
- Encontrar o maior número
- Encontrar o menor número

Objetivo

Percorrer uma lista de números e calcular algumas informações sobre seus valores.

Este projeto faz parte da minha evolução no aprendizado de Java.
